# Import Protocols

## Overview

Import protocols (`IMPPROT`) are files generated by the bank after an upload finishes with status `I` (import started).

## Polling

Use `GetDownloadFileList v4` with `FileTypes=["IMPPROT"]` and the same `ClientAppGuid`.

## Pairing

Protocols are paired with uploads by `UploadFileHash` (SHA256).

## Usage

```python
protocols = await client.poll_import_protocols(target_dir=Path("/data/protocols"))
```

## Format

The protocol format is `pain.002` ČSOB. See the bank's documentation for field-level details.

## Metrics

- `import_protocol_soap_calls` — counter
- `import_protocol_file_count` — gauge
- `import_protocol_download_success` — counter
- `import_protocol_download_latency_seconds` — histogram
